# Polar superposition codes for the BSBC — conference paper draft

**Finite-Blocklength Construction of Polar Superposition Codes for the Binary Symmetric Broadcast Channel.** Paul Sheldon, Natasha Devroye, and Besma Smida, University of Illinois Chicago.

This is a conference-length draft adapted from a chapter of the first author's PhD thesis (UIC, 2026). It is formatted with IEEEtran `conference`. The draft is under review and not yet submitted.

## Build

```
pdflatex main && bibtex main && pdflatex main && pdflatex main
```

This also works on Overleaf as-is. `main.pdf` is a preview built with Tectonic, which uses Latin Modern instead of IEEE's Times; a pdflatex build gives Times and runs slightly shorter.

The PDF contains two kinds of red markers:

- `[Note: …]` marks information that still has to be supplied.
- `[Review: …]` marks a suggested improvement.

To hide either kind, replace its definition in the preamble (`\authornote` or `\reviewnote`) with `\newcommand{...}[1]{}`. Without the markers, the paper fits in about five pages.

## Regenerating Fig. 5

```
python3 scripts/normal_approx.py
```

The script needs only numpy and matplotlib and runs for several minutes. It checks the closed-form moments of Proposition 1 against exact enumeration, prints the normal approximations at n = 128 for comparison with Fig. 4, and writes `figures/crossover.{pdf,csv}`.
