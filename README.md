# Polar superposition codes for the BSBC — conference paper draft

**Finite-Blocklength Construction of Polar Superposition Codes for the Binary Symmetric Broadcast Channel.** Paul Sheldon, Natasha Devroye, and Besma Smida, University of Illinois Chicago.

This is a conference-length draft adapted from a chapter of the first author's PhD thesis (UIC, 2026). It is formatted with IEEEtran `conference`. The draft is under review and not yet submitted.

## Build

```
pdflatex main && bibtex main && pdflatex main && pdflatex main
```

This also works on Overleaf as-is. `main.pdf` is a preview built with Tectonic, which uses Latin Modern instead of IEEE's Times; a pdflatex build gives Times and runs slightly shorter.

The PDF contains two kinds of red markers:

- `[Note: …]` marks information that still has to be supplied.
- `[Review: …]` marks a suggested improvement.

To hide either kind, replace its definition in the preamble (`\authornote` or `\reviewnote`) with `\newcommand{...}[1]{}`. Without the markers, the paper fits in about five pages.

## Technical report: superposition beyond binary alphabets

`reports/superposition_alphabets.tex` (built PDF alongside) is separate from the paper. It tests the paper's conjecture that larger alphabets favour superposition:

- **2-bit symbols — no.**
  - With power-domain 4-point constellations, the best layout is the orthogonal I/Q split, which equals TDM with power control.
  - With discrete models, the quaternary symmetric BC needs 2^10 to 2^12 symbols to beat TDM, and hard-decision Gray QPSK is exactly two BSBC uses per symbol.
- **3-bit symbols — yes.** Hard-decision Gray 8PSK and rectangular 8QAM protect their bits unequally. Splitting the bits between the users (the weak user takes the robust bits) beats TDM with power control from about 128 symbols.
  - Each user's layer is then an ordinary point-to-point polar code.
  - Mixing split modes across symbols gives continuous control of the rate split.
  - Polar simulations at n = 128 (SC decoding) confirm it: mode mixing beats every simulated TDM point, and the paper's construction falls far behind.

To build it, run from `reports/`:

```
pdflatex superposition_alphabets && bibtex superposition_alphabets && pdflatex superposition_alphabets && pdflatex superposition_alphabets
```
